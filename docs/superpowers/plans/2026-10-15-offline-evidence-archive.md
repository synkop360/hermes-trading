**Goal:** Determine which evidence-preservation and storage claims an archive can prove on synthetic copies without touching live data.

**Architecture:** Preserve complete quiescent fixture snapshots as ordered, immutable manifests referencing bounded losslessly compressed content objects. ## Format and recovery contract

Each seal records experiment identity, consecutive first/last batch ordinals, predecessor manifest digest, explicit synthetic-only purpose, and a complete sorted file inventory. Each file contains original byte length, SHA256 and ordered object hashes. Objects are at most 1MiB decoded, compressed with zlib9, addressed by SHA256 and revalidated on reuse. The manifest itself is addressed by canonical-byte SHA256. File paths are relative portable paths without traversal or symlinks; case collisions are rejected for Windows restoration.

The initial manifest starts at batch1. A successor must share experiment identity and start at predecessor.last_batch+1. Referenced history must validate back to the initial manifest. This catches missing/tampered parents and overlap/gap metadata; it does not independently attest that a claimed ordinal is a genuine settled batch. The experiment verifier must inspect the restored settlement database as well.

New objects and manifests are written through unique temporary files, fsynced, verified and published by atomic replace. The manifest is published last. An interrupted seal may leave unreferenced objects/temp files, but never a valid manifest with unavailable objects. This prototype assumes one offline writer. Concurrency, directory power-loss durability and online checkpointing are not certified.

Restore validates the full chain and object/hash/size bounds before publishing a fresh target directory. Existing targets are rejected. Partial staging is retained after failure for diagnosis and is never a valid restored target. Original account/strategy/history bytes are restored exactly. Readers use the restored complete database, so no production reader changes are necessary for this proof.

For eventual production, a bounded active journal needs immutable row/sequence segments, archive-aware reads or a verified complete local materialization, original entry-contract residency and exact journal/peak/risk/model/publication continuity. Remote retirement requires durable verified local acknowledgement plus an independent recoverable copy, an explicit crash-safe cutover and measured source+staging+journal peak capacity. None follows merely from this snapshot codec. If the offline result leaves this gap, report it rather than claiming launch readiness.

## Review focus

1. Tampering, missing objects/parents and reordered/overlapping batch ranges must fail closed.
2. Bounded decoding, traversal and symlinks must not escape or exhaust restore resources.
3. Interruption before manifest publication must preserve source and allow a fresh retry.
4. WAL/current state must not be silently omitted; frozen-source preconditions are explicit.
5. Exact restored finance and sequence equality must include reserve candidate and original eight-wallet data, not just codec tests.
