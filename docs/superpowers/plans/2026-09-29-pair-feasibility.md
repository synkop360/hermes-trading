# SOL/XRP pair relationship prerequisite

Registered before computing relationship diagnostics, September29,2026. This is an exploratory prerequisite, not a profitability backtest or a replication. User constraints: USD50, France, free research, no orders, unchanged risk caps.

Motivation: https://arxiv.org/abs/2109.10662 studies cryptocurrency cointegration with attention to bid/ask execution. It does not establish SOL/XRP profitability or current applicability. This pair is fixed by our prior small-contract shortlist, not selected from a search for the best statistical result. Protocol does not claim this is an exhaustive executable futures universe.

Use only calendar2022 daily closes at 23:00 hourly-bar timestamps from existing hash-verified Bybit perpetual prices; 365 aligned observations. Fixed regression log(SOL) = intercept + beta * log(XRP) + residual. Do not reverse dependent variables to obtain significance. Augmented Engle-Granger with constant, maxlag7, autolag=None; threshold p<0.05 and beta>0 to justify further consideration. Seven fixed lags cover one week at daily frequency, an engineering choice rather than an optimized lag. Report each log-price ADF and first-difference ADF with constant and same7 fixed lags to disclose the assumed integration order. Failure to reject a unit root is not proof of one. If level rejects at5% or first difference fails to reject, flag model assumptions and do not advance on cointegration alone.

Report full-year daily-return correlation, OLS beta, residual AR(1) slope/half-life if 0<rho<1, residual standard deviation, and separately first/second-half betas as descriptive stability diagnostics. Half-life is descriptive and conditional on the fitted process, not a reliable holding-period estimate when the prerequisite fails. No scoring 2023+ and no rolling-window or alternative-pair search following failure. Do not claim failure proves the pair can never mean revert.

On a passing prerequisite, a subsequent separately frozen design must test temporal stability, costs, signed funding, rounding of both legs, delayed bid/ask execution, margin, portfolio risk and USD50 order sizing. Positive cointegration is not evidence of positive expected trading returns. At Kraken base taker0.05% perleg, two equal-dollar legs entered/exited cost0.10% of gross opening notional assuming unchanged prices; adverse0.10% execution perleg adds0.20% of gross. Funding, unequal exit notionals and bills are additional. Do not confuse four fills with0.20% of gross. Source: https://support.kraken.com/articles/fees-for-derivatives-trading-eea .

Freeze script, protocol, data fingerprints and actual dependency versions into a new immutable result directory. Statistical dependencies run in a separate tool environment, without modifying application requirements. Record the result even if unfavorable. No production implementation is proposed at this stage.
