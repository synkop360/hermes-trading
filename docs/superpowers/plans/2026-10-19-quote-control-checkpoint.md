## Inclusion proof identified during frozen regression

Read-only review traced the actual archive APIs. Cohort A preserves quote bundles; Q1…Qn then retire them and create control records. Only a LATER ordinary cohort B can contain those completed plans and all-eight receipts. Reuse the recorded-retired-B resolution in `archive_quote_retention._verify_archive` (`_checkpoint/_requests`, `_chain`, `_restore`, `_cohort`, `_bind`). B already contains immutable database member pins through its ordinary manifest; no additional manifest per quote chunk is needed.

The missing primitive is `quote_control_segment_pin`: select an exact contiguous original control prefix from restored B, verify original plan/progress bytes and rowids plus all eight receipt records against the current prefix, validate both cohorts, and return a purpose-bound logical inclusion pin. Preserve B's captured floor records as observed; current floors can legitimately advance through a later detailed tail, so byte equality of ALL current floors is not a valid requirement. Use current complete-cohort validation to prove that later authority, while comparing the immutable selected receipts exactly. Do not call `_verify_plan_originals(Q,B)`: Q's deleted bundles are absent from B and remain referenced through A.

Ruling: preserve original SQL control rowids as retention ordinals, and explicitly allocate later rows above the checkpoint high-water even when compaction empties the table. Bind new request identities to purpose/cohort/ordinal so a compacted UUID cannot be reused with a new ordinal; keep legacy prototype identity handling explicit. This is separate from shared batch/archive counters.

Ruling: a terminal replay rule must identify lineages already terminal at B's cut, rather than relying on timestamps alone. Retain the captured positions rowid high-water and the small set of captured nonterminal position identities. A position that closes after B remains excluded from the compacted terminal rule until a later cut, even if its close timestamp equals B's timestamp. This preserves the after-interruption protective-write requirement with bounded authority.

Required first native cases: A cannot prove Q's later controls; B proves the selected prefix; a later current tail may advance floors without invalidating that prefix; semantically equivalent but byte-changed current plans/receipts do not match original evidence; unavailable or contradictory B cannot authorize deletion. The full two-rollover mutation/recovery contract above remains required after this inclusion primitive.
